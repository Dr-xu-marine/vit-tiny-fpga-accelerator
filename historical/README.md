# Historical recipes (review only)

Files ending `.tcl.txt` or `.py.txt` are unmodified historical recipes. They contain original absolute paths, stage assumptions, old authorizations and output directories. They are NOT executable release entry points. Do not remove the suffix and run them against the original workspace. Use the source manifest and explicit path rebinding in a new release-local build directory.

The original competition README/evidence contains paths and status at the time it was written; consult the release README and SOURCE_MAP for the public layout. Original report PDF/DOCX/figures were copied, not edited or re-rendered.
